## Driving the deck

| Key | |
|---|---|
| <kbd>→</kbd> <kbd>←</kbd> <kbd>space</kbd> | navigate |
| <kbd>a</kbd> | jump to the agenda from anywhere |
| <kbd>n</kbd> | speaker notes — every slide has them |
| <kbd>o</kbd> | slide overview / jump to any slide |
| <kbd>t</kbd> | session timer, with an on-pace target |
| <kbd>f</kbd> | fullscreen |
| <kbd>p</kbd> | print → save as PDF |
| <kbd>Home</kbd> <kbd>End</kbd> | first / last slide |
| <kbd>?</kbd> | key list |

There are also on-screen controls bottom-right — previous, next, agenda,
overview, notes. They stay faint until you move the mouse. On a phone, swipe
left and right.

<Aside type="tip" title="The agenda slide is clickable">


Slide 4 lists the six blocks; every row jumps to that section. Press
<kbd>a</kbd> to get back to it at any point — the block you came from stays
marked, which is useful when a question sends you sideways.

</Aside>

## Slides vs this site

They're deliberately different, not two copies of the same thing.

**The slides** are built for a room: big type, one idea per slide, a live demo in
the middle. They assume someone is talking over them.

**This site** is built for you alone, weeks later: full explanations, working
code, copy-pasteable commands, and the troubleshooting that a live session never
has time for.

If you attended and want the reference, you want [Learn](../learn/). If you
want to rebuild it, you want [Build](../build/). The deck is best as a quick
visual reminder of the shape of the argument.

## Offline copy

Open the deck and press <kbd>p</kbd> to print it to PDF. Worth doing before you rely on
it — the deck also serves as the backup when a projector, a network, or a laptop
misbehaves.
