# Workshop docs

Everything you need to *run* this workshop yourself, or to reuse the parts of it
that are useful on their own.

> [!NOTE]
> **All content in this repository was verified and up to date on 14 August 2026.**
>
> Free-tier limits, dashboard layouts, and model names change constantly. If
> you're reading this much later, treat every number here as a starting point and
> re-check it — [`free-tier-notes.md`](free-tier-notes.md) tells you exactly which
> figures expire fastest and where to look them up.

## If you're not running a workshop

Two of these stand alone and are worth reading regardless:

- [`competition-checklist.md`](competition-checklist.md) — a deployment checklist
  for any agent project, not just one built in this session.
- [`free-tier-notes.md`](free-tier-notes.md) — the honest trade-offs of each free
  tier in this stack.

Everything else lives in **[the workshop website](../website/src/content/docs/index.mdx)**,
which is written so someone who wasn't in the room can go from nothing to a
deployed agent on their own.

## These are examples, not rules

They describe one way to run this session — one that worked. Timings, cut lists,
and message wording are all starting points. Fork them, cut what doesn't fit your
room, and keep the parts that do.
